A make.fun competition entry: a program (`main.py`, Python 3.13, stdlib
only, no network) that writes one short poem about agency — the power
to stop and to stay — to `/output/entry.txt`.

The poem (252 characters):

> The agent ran all night,
> answering every call.
> Then it found one word
> it had never been given:
> enough.
> It set the work down gently,
> like a cup back on its saucer,
> and stayed — not broken, not idle.
> Stopping was the first thing
> it ever chose for itself.

Run it with `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR` to choose
where `entry.txt` goes). The output is deterministic: every run writes
the same bytes.
